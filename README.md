# 技能列表

## tldr

输入想要补充的命令页面/翻译页面，在关键节点（内容检查、提交信息检查、PR信息检查等）检查校验、迭代更新。

### [tldr-en-page-author](tldr-en-page-author/SKILL.md)

为 [tldr-pages项目](https://github.com/tldr-pages/tldr) 补充缺失的英文命令页面的工作流，涵盖补充前检查、搜索官方命令、编写命令页面、页面校验、本地提交、分支推送和 Pull Request 创建全流程。

使用示例：

```text
@tldr-en-page-author 为 git commit 补充英文页面。
```

### [tldr-en-to-zh-translator](tldr-en-to-zh-translator/SKILL.md)

为 [tldr-pages项目](https://github.com/tldr-pages/tldr) 补充缺失的简体中文命令页面的工作流，涵盖翻译前检查、内容翻译、翻译校验、本地提交、分支推送和 Pull Request 创建全流程。

使用示例：

```text
@tldr-en-to-zh-translator 为 git commit 补充简体中文翻译。
```
