# 技能列表

## [tldr-en-to-zh-translator](tldr-en-to-zh-translator/SKILL.md)

为 [tldr-pages项目](https://github.com/tldr-pages/tldr) 补充缺失的简体中文命令页面的工作流，涵盖翻译前检查、内容翻译、翻译校验、本地提交、分支推送和 Pull Request 创建全流程。

只需要输入想要补充的命令，然后在关键节点（内容检查、提交信息检查、PR信息检查等）检查校验、迭代即可。

使用示例：

```text
使用 $tldr-en-to-zh-translator 为 jq 和 git commit 补充简体中文翻译。
```
